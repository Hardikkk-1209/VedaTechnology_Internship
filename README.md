# Veda Technology Internship

## Day 4: Functions for Reusable Data Tasks

The Day 4 work focuses on reusable Python functions for common data science calculations and transformations.

### Day 4 includes

- Mean, maximum, minimum and percentage calculations
- Reusable parameters and return values
- Data normalization and threshold analysis
- Student marks and sales examples
- A marks transformation example
- Interview question answers

Notebook: `day4_functions.ipynb`

## Day 5: Python Lists, Tuples, Sets and Dictionaries

The Day 5 work focuses on Python collection types and practical operations for structured data.

### Day 5 includes

- Lists with append, remove, update and sort operations
- Tuples and indexed access
- Sets, duplicate removal and set operations
- Dictionaries with key-value access and updates
- Student and employee dataset examples
- Common collection methods
- A comparison table for all four collection types
- Interview question answers

Notebook: `day5_collections.ipynb`

## Run

Open either notebook in Jupyter Notebook, JupyterLab or Google Colab and run the cells from top to bottom.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab

No external Python packages are required.
