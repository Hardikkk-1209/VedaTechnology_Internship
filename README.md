# Veda Technology Internship

## Day 4: Functions for Reusable Data Tasks

This repository contains my Day 4 Data Science internship work focused on reusable Python functions.

### What is included

- Mean, maximum, minimum and percentage calculations
- Reusable parameters and return values
- A normalization function for numeric data
- A threshold-counting function
- A small marks transformation example
- Examples using student marks and employee-style sales data
- Interview question answers from the task brief

### Run

Open `day4_functions.ipynb` in Jupyter Notebook or JupyterLab and run the cells from top to bottom.

### Requirements

- Python 3
- Jupyter Notebook or JupyterLab

No external Python packages are required.
